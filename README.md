## 📋 نبذة عن المشروع

هذا موقع شخصي (Portfolio) مصمم بشكل احترافي لعرض المهارات والمشاريع والخبرات. الموقع مبني بتقنيات الويب الأساسية (HTML, CSS, JavaScript) ويتميز بتصميم عصري ومتجاوب يعمل على جميع الأجهزة.

## ✨ المميزات

- ✅ **تصميم عصري واحترافي** - واجهة مستخدم جذابة ومنظمة
- ✅ **متجاوب تماماً** - يعمل بشكل مثالي على الموبايل، التابلت والكمبيوتر
- ✅ **تأثيرات حركية سلسة** - animations وtransitions احترافية
- ✅ **أداء سريع** - تحميل سريع وتجربة مستخدم ممتازة
- ✅ **SEO Friendly** - محسّن لمحركات البحث
- ✅ **سهل التعديل والتخصيص** - كود نظيف ومنظم مع تعليقات واضحة
- ✅ **دعم كامل للغة العربية** - RTL support

## 🚀 كيفية الاستخدام

### عرض محلي:
```bash
# 1. استنسخ المستودع
git clone https://github.com/gbrw/gh-wesite.git

# 2. افتح المجلد
cd gh-wesite

# 3. افتح index.html في المتصفح
# أو استخدم Live Server في VS Code
```

### النشر على GitHub Pages:

1. اذهب إلى **Settings** في المستودع
2. اختر **Pages** من القائمة الجانبية
3. في **Source**، اختر **Branch: main**
4. احفظ التغييرات
5. الموقع سيكون متاح على: `https://gbrw.github.io/gh-wesite`

## ✏️ التخصيص

يمكنك تخصيص الموقع بسهولة حسب احتياجاتك:

### 1. تغيير المعلومات الشخصية:
- افتح `index.html`
- ابحث عن الأقسام واستبدل المعلومات:
  - الاسم
  - الوصف
  - المهارات
  - المشاريع
  - معلومات التواصل

### 2. تغيير الألوان:
```css
/* افتح style.css وعدّل CSS Variables */
:root {
  --primary-color: #6366f1;     /* اللون الأساسي */
  --secondary-color: #8b5cf6;   /* اللون الثانوي */
  --accent-color: #10b981;      /* لون التمييز */
  /* ... */
}
```

### 3. إضافة مشاريعك الحقيقية:
```html
<!-- في index.html، ابحث عن قسم المشاريع -->
<div class="project-card">
    <div class="project-icon">
        <i class="fas fa-your-icon"></i>
    </div>
    <h3>اسم مشروعك</h3>
    <p>وصف مشروعك...</p>
    <div class="project-tech">
        <span>التقنية 1</span>
        <span>التقنية 2</span>
    </div>
    <a href="رابط_github" class="project-link">
        <i class="fab fa-github"></i> عرض الكود
    </a>
</div>
```

### 4. تعديل نموذج التواصل:
حالياً النموذج يعمل على مستوى العميل (client-side). لإضافة إرسال حقيقي:
- استخدم خدمة مثل [Formspree](https://formspree.io/)
- أو [EmailJS](https://www.emailjs.com/)
- أو اربطه بـ Backend خاص بك
